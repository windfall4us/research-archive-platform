## 一、定位

**Observation Lock 是运行阶段定义，不是功能版本。** 系统已完成全部功能建设，进入「数据证明阶段」：

```
资讯 → 分类 → 事件 → 图谱 → 研究对象 → Research Score → 验证
→ 每日观察日报 → 人工决策
```

当前最有价值的资产是**真实样本数据**——未来 20+ 交易日的验证结果决定 v2.4 是否调参、怎么调。

## 四、市场环境标签（v2.3.4e 新增）

**目的**：为 v2.4 判断「RS 在何种市场环境有效」（强势/震荡/弱势分组），避免错误调权重。

**判定逻辑**（无指数数据，用研究池等权代理）：
```
强势: 上涨家数≥60% 且 近5日均幅 - 前20日均幅 ≥ +0.3pp
弱势: 上涨家数≤40% 且 趋势 ≤ -0.3pp
震荡: 其余
```

**写入位置**：
- 每日观察日报头部（md + 报告站 HTML）
- `research_system_snapshot.market_regime`（逐日记录）

**今日实测示例**：`📈 市场环境: 震荡（上涨132/302 44% · 涨停≈11 · 近5日均幅+0.57% vs 前20日+0.73% · 趋势-0.16pp）`

## 五、每日观察流水线（自动运行）

```
21:30  archive_quality_check_v223.py       质量检查（数据健康）
21:40  archive_validation_snapshot_v234c.py 验证快照（T+1/3/5 回填）
21:45  archive_obs_v234.py                 系统快照（research_system_snapshot）
21:50  archive_obs_report_v234d.py         观察日报生成（observation_reports/）
```

日报覆盖指标：RS 分层 × 表现、同 RS 档内 GS/Confidence 细分、Momentum 分层、十模型贡献、市场环境、T+10/T+20（从 kline 现算）。

## 六、观察期纪律（锁定）

### ✅ 只做
- 数据异常修复（空数据/分类误判/API 错误）
- 前端排版/信息层级优化（不改模型）
- 日报自然积累 + 必要修复
- 质量监控数据治理可视化（机构异常分级/低置信度拆分/重复归并）

### ❌ 不做
- 新模块 / 新算法 / 新评分 / 新状态
- 参数调整 / 权重修改（RS/Momentum/Graph/十模型）
- 自动权重优化 / 自动策略优化
- 接交易系统 / 自动买卖 / 自动改持仓
