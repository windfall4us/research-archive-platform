# 资讯研究档案库 — 数据流设计图（v2.2.1 实际运行版）

> 保存日期：2026-08-12（基于 VPS2 实际运行的 v2.2.1 系统核实）

## 一、整体闭环

```
┌────────────────────────────────────────────────────────────────────────────┐
│                    信息获取 → 事件理解 → 影响分析 → 股票关联                  │
│                          → 模型验证 → 研究排序 → 人工决策                    │
└────────────────────────────────────────────────────────────────────────────┘
```

## 三、数据库表（research_archive.db，17 张）

| 分层 | 表 | 职责 |
|---|---|---|
| **原始层** | `raw_messages` | 采集原始消息 |
| **归一化** | `normalized_messages` | 去重/标准化后的消息 |
| **分类** | `message_classification` | 8 类互斥 + 多维标签 |
| **归并** | `report_series` / `report_versions` / `report_occurrences` / `report_messages` / `report_entities` / `report_verifications` | 研报系列→版本→出现→消息→实体→验证 |
| **事件** | `event_clusters` / `event_messages` / `event_momentum` / `event_stock_relation` | 事件聚类、消息关联、动量、股票映射 |
| **候选** | `event_watch_pool` | 事件观察池（研究队列）|
| **评分** | `research_scores` / `research_summary` / `research_validation` | 研究综合分、结论、验证 |

## 四、人工决策入口（页面）

```
ArchivePage (资讯研究终端)
  ├── 事件中心 → 事件详情: 核心事实 → 来源传播 → 机构观点 → A股映射 → 后续更新
  ├── 研究队列 → 候选推进 (EVENT_FOUND→…→TRIAL_READY) + 人工备注
  └── 个股/行业追踪 → 自选股联动
        │
        ▼
watchlist 主站 (v4.2.8): 自选股/持仓/问股 页面 → 十模型检查 → 交易决策
```

---

**核心设计思想**：**采集→清洗→分类→机构标准化→研报归并→LLM/Vision提取→版本管理→观点验证→质量监控** 全闭环；每 30 分钟增量跑一遍（v2→v21b 顺序执行），数据落库后由 archive_server 提供 API，最终在 ArchivePage 呈现给用户做人工决策。
